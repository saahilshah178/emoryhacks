# emoryhacks

One app, one port. Start the site from the repo root or from `frontend/landing`.

```bash
npm install --prefix frontend/landing
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Landing: `/`
- Caregiver portal: `/portal`
- Nurse dashboard: `/dashboard`

Use **Log in** or **Demo access** to move between them without changing ports. **Sign out** returns to the landing page.
