# emoryhacks

Start the landing site on port 3000, the nurse dashboard on 3001, and the caregiver portal on 3002.

```bash
cd frontend/landing
npm install
npm run dev
```

```bash
cd frontend/dashboard
npm install
npm run dev
```

```bash
cd frontend/caregiver-portal
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use **Log in** to choose the caregiver portal or clinical dashboard.
